当前输出的轨迹图是按每秒更新的，精度需要稍微修改代码。
之前修改代码时可能用了 std::setprecision(6)，或者没有设置固定小数位，导致 C++ 默认以 6 位有效数字输出。
对于时间戳 1791881234.567890：
6 位有效数字 → 1.79188e+09（小数部分全丢了）
你需要的是 → 1791881234.567890（保留到微秒）

需要在 oh_my_loam.cc 中，把 setprecision 改大，并加上 std::fixed：
// 错误（之前可能写的）：
traj_ofs_ << std::fixed << std::setprecision(6);  
// 这样只会输出 6 位小数，但整数部分还是会被科学计数法影响？不，fixed 会固定小数位
// 实际上 fixed + setprecision(6) 应该输出 1791881234.567890
// 但如果你看到 1.79188e+09，说明可能没有加 fixed，或者精度设置不对

// 正确做法：
traj_ofs_ << std::fixed << std::setprecision(9);  // 9位小数，覆盖纳秒级
